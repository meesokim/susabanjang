# 수사반장 1970

**THE COLD TRUTH** · 제1화 「빗줄기 속의 거수」

1972년 장마, 명동 한일은행. 인질 열두 명, 군용 카빈, 내려앉은 셔터. 종남경찰서 수사과 박영한 반장이 말과 증거로 문을 연다.

브라우저에서 하는 포인트 앤 클릭 수사 게임이다. 화면 위를 걷는 대신, 인물과 행동과 대상을 골라 한 문장을 만든다.

플레이: [https://meesokim.github.io/susabanjang/](https://meesokim.github.io/susabanjang/)

## 개요

순찰차 안에서 브리핑을 듣고 차문을 연다. 은행 앞 인도에서 탄피, 확성기, 자필, 탄창 속 쪽지를 모아 셔터 안의 공모자를 가린다. 문이 열리면 3×3 조준으로 인질을 살리고, 주모자는 오른손목만 맞춘다. 코트에서 나온 영수증이 다음 주소다.

제1화에서 끝난다. 제2화는 엔딩 뒤 봉인되어 있고 플레이되지 않는다.

함께하는 형사:

| 인물 | 역할 |
| --- | --- |
| 박영한 | 반장. 플레이어 |
| 김상순 | 압박 |
| 조경환 | 돌파 |
| 서호정 | 감식 |

등장인물의 얼굴은 배우를 닮지 않은 픽셀이다. 오프닝 GIF와 MIDI는 이 게임을 위해 새로 만든 영상이고, 방송 주제가는 쓰지 않는다.

## 조작

화면 아래는 세 칸이다. 왼쪽이 인물, 가운데가 행동, 오른쪽이 대상이다. 설명이 없어도 칸은 빈자리로 남는다.

| 키 | 행동 |
| --- | --- |
| 1 | 준다 |
| 2 | 연다 |
| 3 | 닫는다 |
| 4 | 집는다 |
| 5 | 본다 |
| 6 | 말한다 |
| 7 | 사용 |
| 8 | 민다 |
| 9 | 당긴다 |

- 오른쪽 클릭은 언제나 「본다」.
- 「사용」과 「준다」는 인물이나 물건을 먼저 고르고, 다음 대상을 누른다.
- N은 수사수첩. 단서 둘을 눌러 맞댄다.
- S는 이 브라우저에 조서를 남긴다.
- 셔터를 뜯을 때는 버튼이나 스페이스를 연타한다.
- 교전의 숫자는 키패드 배치다. 7 8 9가 위, 4 5 6이 가운데, 1 2 3이 아래다. 6이 오른손목이다.
- R은 재장전. 스페이스는 조경환의 엄호, 한 번.
